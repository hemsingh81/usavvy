We've plotted house price against square footage. Notice how the points roughly follow a rising trend — as size goes up, price tends to go up too. If we wanted a single line that captures this trend as closely as possible, how would we choose it?

The cost function J(θ) measures how far off our line is, on average, across every point. Right now we're minimizing the squared distance between each point and the line
J(θ) = (1 / 2m) · Σ (hθ(xᵢ) − yᵢ)²
